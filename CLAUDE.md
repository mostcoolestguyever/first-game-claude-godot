# New Game Project

A new Godot 4.6 game project. It currently holds only the default project files (`project.godot`, `icon.svg`); no scenes or scripts yet.

- Engine: Godot 4.6
- Renderer: GL Compatibility (Direct3D 12 driver on Windows)
- 3D physics: Jolt Physics
- `.godot/` is the editor's generated cache and is gitignored; don't edit it.
- `project.godot` is best changed through the Godot editor rather than by hand.

## Rules

- Split work into small stages. After each stage, stop so the user can play-test and debug it in Godot before continuing.
- Only open a pull request when the user asks for one.
